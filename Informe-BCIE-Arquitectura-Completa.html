1. Visión General del Sistema

El sistema informe-bcie es una aplicación web para gestionar informes ambientales y sociales en proyectos escolares. Está construido como una aplicación monolítica con arquitectura de capas.

Componentes Principales

🎨 Frontend (React)

Interfaz de usuario con 12+ páginas, componentes reutilizables y generación de PDFs en cliente

⚙️ Backend (Next.js API)

11+ endpoints para gestión de informes, usuarios, escuelas y descarga de archivos

🗄️ Base de Datos (PostgreSQL)

Supabase con 17+ tablas incluyendo informes, módulos, perfiles y escuelas

Stack Tecnológico

3. Flujo de Autenticación

Proceso de Login Paso a Paso

1. Usuario entra a /login └─ Página LoginForm (client component) 2. Usuario ingresa username + password └─ Escucha evento onSubmit del formulario 3. Frontend llama POST /api/lookup-user └─ Busca email asociado al username 4. Backend retorna email (o error) └─ Si error → mostrar "Usuario incorrecto" 5. Frontend llama supabase.auth.signInWithPassword() └─ Supabase valida email + password 6. Si éxito: Supabase retorna JWT token └─ Token almacenado en cookies 7. Frontend llama supabase.auth.getUser() └─ Obtiene perfil del usuario 8. Determina rol y redirige: └─ rol === 'usuario' → /informes └─ rol === 'programador' → /dashboard └─ rol === 'administrador' → /dashboard 9. Router.push(destino) └─ Usuario ve página protegida

Roles Actuales en el Sistema

Rol Acceso Principal Características Especiales
programador /dashboard, /informes, /usuarios, /escuelas, /reportes Acceso a seed-users, puede crear usuarios demo
administrador /dashboard, /informes, /usuarios, /escuelas, /reportes Gestión completa de usuarios y escuelas
usuario /informes (restringido) Solo ve informes de su empresa de supervisión
visitante /informes (demo) Solo lectura, solo escuelas de demostración

// app/(app)/layout.tsx
export default async function AppLayout({ children }) {
  // 1. Obtener usuario autenticado
  const supabase = await createClient()
  const { data: { user } } = await supabase.auth.getUser()

  // 2. Si no está autenticado → redireccionar a /login
  if (!user) {
    redirect('/login')
  }

  // 3. Obtener perfil de la BD
  const { data: profile } = await supabase
    .from('profiles')
    .select('*')
    .eq('id', user.id)
    .single()

  // 4. Pasar perfil a Sidebar y mostrar UI protegida
  return (
    <Sidebar profile={profile} />
    <main>{children}</main>
  )
}

5. Ciclo de Vida de un Informe

Estados de un Informe

1. BORRADOR (Estado inicial) ├─ Usuario crea informe nuevo ├─ Puede editar todos los módulos ├─ No visible para otros usuarios └─ Guardar es automático (autosave) 2. ENVIADO ├─ Usuario presiona "Enviar" ├─ Informe visible para coordinadores ├─ Coordinador puede ver pendientes └─ Usuario no puede editar 3. OBSERVADO (opcional) ├─ Coordinador agrega observaciones ├─ Si hay observaciones → estado "observado" ├─ Usuario ve observaciones └─ Usuario puede editar para resolver 4. RESUELTO ├─ Usuario resuelve observaciones ├─ Marca observaciones como resueltas ├─ Vuelve a ENVIADO └─ Coordinador revisa de nuevo 5. APROBADO (Final) ├─ Coordinador aprueba ├─ Informe completado ├─ Botón de descarga PDF habilitado └─ No se puede editar más

Transiciones Permitidas

Estado Actual Usuario (rol) Acción Posible Nuevo Estado
borrador usuario/especialista Hacer clic en "Enviar" enviado
enviado coordinador Agregar observaciones observado
enviado coordinador Hacer clic en "Aprobar" aprobado
observado usuario/especialista Resolver observaciones resuelto
resuelto coordinador Revisar y aprobar aprobado

Flujo Completo de un Usuario

ESPECIALISTA (usuario especialista)
1. Va a /informes
2. Busca escuela y mes/año
3. Si no existe → hace clic "Nuevo Informe"
4. Sistema crea borrador vacío
5. Navega por módulos (HSSO, MAQR, PPPI, etc)
6. Completa cada módulo con datos
7. Cada cambio se guarda automáticamente
8. Cuando termina → hace clic "Enviar"
9. Informe cambia a estado "enviado"
10. Ya no puede editar

COORDINADOR (usuario coordinación)
11. Ve informe en estado "enviado"
12. Revisa cada módulo
13. Si hay problemas → agrega "Observaciones"
14. Sistema marca informe como "observado"
15. Especialista es notificado

ESPECIALISTA (nuevamente)
16. Ve que hay observaciones
17. Va a la sección "Pendientes"
18. Lee observaciones
19. Va al módulo correspondiente
20. Corrige lo que se pide
21. Marca observación como "Resuelta"
22. Informe cambia a "resuelto"

COORDINADOR (final)
23. Revisa correcciones
24. Si todo está bien → hace clic "Aprobar"
25. Informe cambia a "aprobado"
26. Especialista puede descargar PDF

Ejemplo de API Route: Descarga de PDF

// app/api/informes/[id]/pdf/download/route.ts
export async function GET(req, { params }) {
  try {
    // 1. VERIFICAR AUTENTICACIÓN
    const supabase = await createClient()
    const { data: { user }, error: authError } =
      await supabase.auth.getUser()

    if (authError || !user) {
      return NextResponse.json(
        { error: 'No autenticado' },
        { status: 401 }
      )
    }

    const { id } = await params

    // 2. VERIFICAR PERMISOS
    const { data: userProfile } = await supabase
      .from('profiles')
      .select('rol')
      .eq('id', user.id)
      .single()

    // 3. OBTENER INFORME
    const { data: informe, error: informeError } = await supabase
      .from('informes')
      .select(`
        *,
        escuelas(nombre, codigo, grupo_id, grupos(numero))
      `)
      .eq('id', id)
      .single()

    if (informeError || !informe) {
      return NextResponse.json(
        { error: 'Informe no encontrado' },
        { status: 404 }
      )
    }

    // 4. VERIFICAR SI ESTÁ APROBADO
    if (userProfile?.rol !== 'administrador' &&
        userProfile?.rol !== 'programador') {
      if (informe.estado !== 'aprobado') {
        return NextResponse.json(
          { error: 'Acceso denegado' },
          { status: 403 }
        )
      }
    }

    // 5. GENERAR PDF CON jsPDF
    const pdfDoc = generarPDF(informe)
    const pdfBlob = pdfDoc.output('blob')

    // 6. RETORNAR COMO DESCARGA
    const filename =
      `Informe_${informe.escuelas?.codigo}_${informe.periodo_anio}-${informe.periodo_mes}.pdf`

    return new NextResponse(pdfBlob, {
      headers: {
        'Content-Type': 'application/pdf',
        'Content-Disposition': `attachment; filename="${filename}"`,
        'Cache-Control': 'no-store',
      },
    })

  } catch (error) {
    console.error('Error:', error)
    return NextResponse.json(
      { error: 'Error al descargar PDF' },
      { status: 500 }
    )
  }
}

function generarPDF(informe) {
  const doc = new jsPDF()

  // Configurar estilos
  const NAVY = '#0f2d52'
  const GOLD = '#c8a951'

  // Portada
  doc.setFillColor(15, 45, 82)
  doc.rect(0, 0, 210, 40, 'F')

  doc.setTextColor(200, 169, 81)
  doc.setFontSize(18)
  doc.text('PROGRAMA MI NUEVA ESCUELA', 105, 15, { align: 'center' })

  doc.setTextColor(255, 255, 255)
  doc.setFontSize(12)
  doc.text('INFORME MENSUAL DE SUPERVISIÓN', 105, 28, { align: 'center' })

  // Datos
  doc.setTextColor(15, 45, 82)
  doc.setFontSize(14)
  doc.text('DATOS DEL INFORME', 20, 60)

  doc.setFontSize(10)
  doc.setTextColor(0, 0, 0)
  doc.text(`Centro: ${informe.escuelas?.nombre}`, 20, 75)
  doc.text(`Código: ${informe.escuelas?.codigo}`, 20, 85)
  doc.text(`Período: ${informe.periodo_mes}/${informe.periodo_anio}`, 20, 95)

  return doc
}

Opción 2: Servidor (jsPDF para descarga en lote)

// app/api/informes/descargar-lote-zip/route.ts
import { jsPDF } from 'jspdf'
import JSZip from 'jszip'

export async function POST(req) {
  const { informeIds } = await req.json()

  const zip = new JSZip()

  // Iterar sobre cada informe
  for (const informeId of informeIds) {
    // Obtener datos del informe desde BD
    const informe = await getInformeFromDb(informeId)

    // Generar PDF con jsPDF
    const pdf = new jsPDF()
    pdf.text('PROGRAMA MI NUEVA ESCUELA', 105, 20, { align: 'center' })
    pdf.text('Centro: ' + informe.escuelas.nombre, 20, 40)
    pdf.text('Período: ' + informe.periodo_mes + '/' + informe.periodo_anio, 20, 50)

    // Agregar PDF al ZIP
    const pdfBlob = pdf.output('blob')
    const filename = `Informe_${informe.escuelas.codigo}_${informe.periodo_anio}-${informe.periodo_mes}.pdf`
    zip.file(filename, pdfBlob)
  }

  // Generar y retornar ZIP
  const zipBlob = await zip.generateAsync({ type: 'blob' })

  return new NextResponse(zipBlob, {
    headers: {
      'Content-Type': 'application/zip',
      'Content-Disposition': 'attachment; filename="informes.zip"'
    }
  })
}

9. Descarga en Lote (ZIP)

Proceso Paso a Paso

1. Usuario va a /descargar-lote └─ Ve formulario de filtros 2. Selecciona filtros: ├─ Rango de meses ├─ Año ├─ Estado (aprobados, todos, etc) ├─ Escuelas └─ Empresa de supervisión (si aplica) 3. Hace clic "Buscar" o "Vista Previa" └─ Llamada a /api/informes/descargar-lote 4. Backend ejecuta query: ├─ SELECT * FROM informes ├─ WHERE periodo_mes IN (...) ├─ AND periodo_anio = ... ├─ AND estado = 'aprobado' ├─ AND escuela_id IN (...) └─ Retorna lista 5. Frontend muestra tabla con resultados ├─ Nombre escuela ├─ Código ├─ Período ├─ Estado └─ Checkbox para seleccionar 6. Usuario selecciona informes ├─ Hace clic checkboxes ├─ Cuenta se actualiza en tiempo real └─ Ejemplo: "Seleccionados: 5 de 23" 7. Usuario hace clic "Descargar ZIP" └─ Llamada a /api/informes/descargar-lote-zip 8. Backend genera PDFs: ├─ Por cada informe seleccionado: │ ├─ Obtener datos de BD │ ├─ Generar PDF con jsPDF │ └─ Agregar al ZIP └─ Retorna archivo ZIP 9. Frontend recibe ZIP ├─ Crea blob ├─ Crea descarga automática └─ Usuario recibe: informes.zip 10. Usuario descomprime ZIP └─ Ve archivos: Informe_CE001_2026-03.pdf, Informe_CE002_2026-03.pdf, ...

Componente DescargarLote

// app/(app)/descargar-lote/page.tsx
'use client'

export default function DescargarLotePage() {
  const [filtros, setFiltros] = useState({
    mesDesde: 1,
    mesHasta: 12,
    anio: 2026,
    estado: 'aprobado',
    supervision: ''
  })

  const [informes, setInformes] = useState([])
  const [seleccionados, setSeleccionados] = useState(new Set())
  const [loading, setLoading] = useState(false)

  // Buscar informes
  async function buscar() {
    setLoading(true)
    const res = await fetch('/api/informes/descargar-lote', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(filtros)
    })
    const data = await res.json()
    setInformes(data)
    setSeleccionados(new Set())
    setLoading(false)
  }

  // Descargar ZIP
  async function descargar() {
    const ids = Array.from(seleccionados)

    const res = await fetch('/api/informes/descargar-lote-zip', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ informeIds: ids })
    })

    const blob = await res.blob()
    const url = URL.createObjectURL(blob)
    const a = document.createElement('a')
    a.href = url
    a.download = 'informes.zip'
    a.click()
  }

  return (
    <div>
      {/* FILTROS */}
      <div className="filtros">
        <input
          type="number"
          placeholder="Mes desde"
          value={filtros.mesDesde}
          onChange={(e) => setFiltros({...filtros, mesDesde: parseInt(e.target.value)})}
        />
        <input
          type="number"
          placeholder="Mes hasta"
          value={filtros.mesHasta}
          onChange={(e) => setFiltros({...filtros, mesHasta: parseInt(e.target.value)})}
        />
        <input
          type="number"
          placeholder="Año"
          value={filtros.anio}
          onChange={(e) => setFiltros({...filtros, anio: parseInt(e.target.value)})}
        />
        <select
          value={filtros.estado}
          onChange={(e) => setFiltros({...filtros, estado: e.target.value})}
        >
          <option value="aprobado">Aprobados</option>
          <option value="">Todos</option>
        </select>
        <button onClick={buscar} disabled={loading}>
          {loading ? 'Buscando...' : 'Buscar'}
        </button>
      </div>

      {/* TABLA DE RESULTADOS */}
      {informes.length > 0 && (
        <>
          <p>Seleccionados: {seleccionados.size} de {informes.length}</p>
          <table>
            <thead>
              <tr>
                <th>
                  <input
                    type="checkbox"
                    onChange={(e) => {
                      if (e.target.checked) {
                        setSeleccionados(new Set(informes.map(i => i.id)))
                      } else {
                        setSeleccionados(new Set())
                      }
                    }}
                  />
                </th>
                <th>Escuela</th>
                <th>Período</th>
                <th>Estado</th>
              </tr>
            </thead>
            <tbody>
              {informes.map(inf => (
                <tr key={inf.id}>
                  <td>
                    <input
                      type="checkbox"
                      checked={seleccionados.has(inf.id)}
                      onChange={(e) => {
                        const nuevo = new Set(seleccionados)
                        if (e.target.checked) {
                          nuevo.add(inf.id)
                        } else {
                          nuevo.delete(inf.id)
                        }
                        setSeleccionados(nuevo)
                      }}
                    />
                  </td>
                  <td>{inf.escuelas?.nombre}</td>
                  <td>{inf.periodo_mes}/{inf.periodo_anio}</td>
                  <td>{inf.estado}</td>
                </tr>
              ))}
            </tbody>
          </table>

          <button
            onClick={descargar}
            disabled={seleccionados.size === 0}
          >
            Descargar {seleccionados.size} PDF como ZIP
          </button>
        </>
      )}
    </div>
  )
}

// Ejemplo: Verificar permiso antes de descargar
async function validarPermiso(userId, informeId, accion) {
  const supabase = await createClient()

  // 1. Obtener rol del usuario
  const { data: user } = await supabase
    .from('profiles')
    .select('rol')
    .eq('id', userId)
    .single()

  // 2. Admin/Programador siempre pueden
  if (['administrador', 'programador'].includes(user.rol)) {
    return true
  }

  // 3. Usuario normal: solo sus informes
  if (user.rol === 'usuario') {
    const { data: informe } = await supabase
      .from('informes')
      .select('creado_por')
      .eq('id', informeId)
      .single()

    return informe?.creado_por === userId
  }

  // 4. Visitante: solo lectura
  if (user.rol === 'visitante') {
    return accion === 'leer'
  }

  return false
}
